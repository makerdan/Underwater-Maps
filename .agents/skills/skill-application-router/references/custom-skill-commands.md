# Custom Skill Command Catalog

Use the command matching the requested skill. These prompts are routing
templates, not substitutes for reading the current target `SKILL.md`; the
current target contract always wins.

## `app-support-ops`

Record each as present, absent, unclear, or not applicable and resolve unclear items from evidence. Select only the requested Help, Admin Analytics, Runtime Safety, or explicitly Combined mode. Runtime Safety applies the relevant Port Authority contract: environment-owned ports, repository scan and fixtures, canonical allocation, exact-holder safe cleanup with production guards, and repeatable validation. Add a development-only outage/restart surface only when its client, controllable process, and production exclusion are proven. Validate enabled, negative, and unavailable-capability paths and report evidence, selected/unselected modes, changes, tests, gaps, and handoffs; never claim an unverified protection.
